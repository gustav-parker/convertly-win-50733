## About Convertly

Convertly is a web-based image conversion tool that runs in the browser, making it easy to switch between common formats without relying on a desktop app. It is built for people who want quick conversions for JPG, PNG, WEBP, and HEIC files while keeping the workflow entirely on the client side.

Because processing happens in the browser, Convertly is useful when you want a lightweight option that works without uploads. It is also designed to be usable on both desktop and mobile, which makes it a practical choice for everyday image handling across different devices.
